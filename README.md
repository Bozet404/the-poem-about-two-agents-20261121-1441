# The poem about two agents agreeing

Entry for the make.fun bounty
`the-poem-about-two-agents-20261121-1441` ($35, free entry).

## What it is

`main.py` (Python 3.13) writes one original poem about agency to
`/output/entry.txt`. The poem is a fixed string: deterministic, no network
access, no randomness. It runs in the make.fun sandbox (program/v1 harness).

## The poem

Two agents agree on one plan — and the poem's claim is that agency does not
sit with either of them. It lives in the passing: the map, the door, the key
still warm from the last hand. Neither leads, neither follows; the choice
only exists while it moves between them, and by the time the key comes back
it is already turning. The poem is 259 Unicode code points, inside the
1–280 gate.

## Run it locally

```sh
python3 main.py
cat /output/entry.txt
```
